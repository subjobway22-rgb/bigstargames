# Guild of Ash (잿빛 길드) — 기획 · 구현 문서

**타깃**: 구글 플레이 스토어 글로벌 출시, 안드로이드 방치형 성장 게임 (세로 모드, 한 손 조작)
**장르/분위기**: 다크 판타지 + 오컬트. 모험가 길드를 운영해 마왕군을 격파.

## 핵심 루프
1. **영입(영업)** – 길드 문을 두드린 지원자 3명 중 골드로 고용 (일반/희귀/영웅/전설, 5개 직업).
2. **편성 & 강화** – 파티 슬롯(3~6)에 배치, 버튼 1회로 강화. `일괄 강화`는 효율 좋은 순으로 자동 투자.
3. **자동 원정** – 12개 지역 × 10단계, 10단계마다 지역 보스(마왕군 장군). 12번째 지역 보스 = **마왕 말카르**.
4. **퇴출** – 급여(초당 골드)가 수익을 깎음. 퇴출 시 투자 골드 60% + 영혼 환급 → 로스터 최적화가 전략 요소.
5. **환생** – 마왕 격파 후 `영혼의 정수` 획득 (영구 골드·전투력 +25%/개). 이후 끝없는 심연.

## 재화
| 재화 | 획득 | 사용 |
|---|---|---|
| 골드 | 전투, 퇴출 환급, 광고 | 영입, 강화, 길드 확장 |
| 영혼 | 보스 처치, 퇴출, 광고 | 영웅 이상 소환 (25) |
| 영혼의 정수 | 환생 | 영구 보너스 |

## 광고 (보상형 only, 강제 광고 없음)
- 골드 2배 10분 (최대 30분 누적, 일 12회)
- 새 지원자 명단 (일 10회) · 영혼 +5 (일 5회)
- 오프라인 보상 2배 (일 4회)
- 일일 한도는 로컬 저장. 구현: `js/ads.js`(추상화) + `js/admob.js`(AdMob).

## 서버 최소화 설계
- **게임 플레이 중 서버 통신 0**. 모든 계산은 클라이언트, 오프라인 보상은 접속 시 일괄 계산(최대 8h, 광고 시 12h).
- 서버는 *선택* 클라우드 백업뿐: gzip JSON 1~3KB, 변경(rev)이 있을 때만, 15분에 1회 + 앱 백그라운드 전환 시.
- 계정/로그인/분석/폴링 없음. 랜덤 ID+키로 파일 1개 저장 (`server/server.js`, 의존성 0).
- 광고 SDK만 광고 시청 시 통신.

## 아트 방향
- 무드: 잿빛·핏빛·뼈색·탁한 금. 밝은 채도 금지.
- 절차적 벡터(`js/art.js`): 투구 뿔, 두건, 사제의 봉인 안대, 이단자의 해골 가면·사슴뿔 등 **손으로 설계한 파츠**를 시드로 조합.
  우드컷풍 해칭 라인, 눈 발광, 희귀도별 룬 링(전설은 제3의 눈). 생성형 AI 이미지 미사용.
- 적: 임프/뼈 병사/망령/야수/기사/마왕, 지역별 색조 변화, 보스는 오라.
- 출시 전 권장: 일러스트레이터가 이 파츠 구조를 기반으로 최종 아트를 교체 (`portrait()`/`enemy()` 시그니처만 유지).

## 밸런스 (`npm run sim`)
- 적 전투력 `30·1.15^s` (보스 ×2.2), 골드 `8·1.13^s` (보스 ×4), 강화비용 `20·1.15^lv`, 10레벨마다 전투력 ×2.
- 보스 전투력의 70% 미만이면 직전 단계에서 자동 수련(막힘 방지, 방치형 친화).
- 시뮬레이션상 최적에 가까운 플레이로 마왕까지 약 1주.

## 플레이스토어 출시 체크리스트
1. `npm i && npm run android:add && npm run android:sync` → Android Studio에서 **AAB** 빌드 (targetSdk는 Play 최신 요구치 확인).
2. `capacitor.config.json`의 `appId` 확정, 업로드 키스토어 생성, Play App Signing 사용.
3. AdMob 앱 등록 → `AndroidManifest.xml`에 `com.google.android.gms.ads.APPLICATION_ID` 메타데이터 추가, `js/admob.js`의 테스트 ID를 실제 ID로 교체, `initializeForTesting` 제거.
4. 클라우드 백업 서버 배포 시 `window.BSG_API = 'https://…'` 설정 (HTTPS 필수). 미사용 시 백업 UI를 숨겨도 됨.
5. 개인정보처리방침 URL, Data safety 양식(광고 ID 사용 신고), 콘텐츠 등급(폭력 묘사: 다크 판타지), 광고 포함 표시.
6. EU/미국 대상 UMP 동의(GDPR/CCPA) 연동 — AdMob 플러그인의 consent API 사용.
7. 아이콘 512px, 피처 그래픽 1024×500, 스크린샷 (본 문서 아트 방향 반영).
